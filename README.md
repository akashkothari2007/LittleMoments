# Little Moments

Little Moments is a cozy 2D pixel-art story game built in Unity.

The game focuses on small interactive tasks and atmospheric storytelling — planting flowers, building paths, lighting a campfire, and progressing through light narrative moments.

---

## 🎮 Features

- 🌸 Plant and decorate a garden
- 🪨 Push rocks to build a path
- 🔥 Light a campfire with simple interaction mechanics
- 🌙 Dynamic day/night transitions
- 🎵 Background music with smooth fading
- ✨ Post-processing effects (bloom, distortion, color grading)
- 💬 Dialogue system with typing animation and sound effects
- 🎬 Basic cutscene transitions

---

## 🛠 Built With

- Unity (URP)
- C#
- TextMeshPro
- Unity 2D Tilemap system
- Unity Post-Processing (Volume system)

---

## 📁 Project Structure

- `Assets/_GAME_/Scenes` – Main gameplay scenes  
- `Assets/_GAME_/Scripts` – Core game systems (StoryManager, effects, interaction logic)  
- `Assets/_GAME_/Audio` – Music and sound effects  
- `Assets/_GAME_/Art` – Sprites and tile assets
